# GitHub repository info

## Repository name

`MI_nodes`

## Description (About field, max 350 characters)

Pack of 6 ComfyUI custom nodes: MI Lora (multi-LoRA, trigger words, Civitai lookup), MI Unet Rate (rate and comment your models), MI Embedding (embedding picker), MI Compare 3 Images, MI Save Image (preview, then save on demand) and MI Reroute Sound (plays a WAV).
